# Felhasznált források

Ez a fájl gyűjti a fejlesztés során **ténylegesen felhasznált** forrásokat – ebből készül a
szakdolgozat irodalomjegyzéke. A kódban az átvett minták mellett komment jelzi a forrást:

```ts
// Forrás: <cím>, <URL> (adaptálva)
```

A **Lekérve** oszlopot akkor töltsd ki, amikor a linket megnyitottad és ellenőrizted (ÉÉÉÉ-HH-NN).
A fejlesztési terv tervezett forrásjegyzéke (S1–S56): `docs/FEJLESZTESI_TERV.md`, 12. fejezet.
